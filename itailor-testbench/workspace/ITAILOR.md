# ITAILOR.md

Instructions for iTailor working in this test workspace.

## Project

- Purpose: a scratch project for testing the iTailor library through the Flask testbench.
- Data lives in: `data/` (products.csv, sales_2026-01.csv, sales_2026-02.csv, sales_2026-03.csv).
- Outputs go to: the project root, with descriptive file names.

## Conventions

- Prefer Python; pandas and matplotlib may or may not be installed - check ENVIRONMENT or let RunCode heal it.
- Never modify the files under `data/`; write new files instead.
- Print a short plain-language summary of findings at the end of every script.
